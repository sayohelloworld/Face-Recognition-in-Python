# Installation Guide

## Requirements

- Python 3.12
- pip
- Windows, Linux, or macOS

## Dependencies

FaceRec relies on the following libraries:

| Library | Purpose |
|---|---|
| face_recognition | Face detection and recognition |
| dlib | Facial feature extraction |
| OpenCV | Image processing and visualization |

## Setup

Clone the repository:

```bash
git clone REPOSITORY_URL
cd FaceRec
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Troubleshooting

If `dlib` fails to install, check the compiler and Python compatibility requirements for your operating system.
